# Security policy

## Reporting a vulnerability

Please don't open a public issue for security problems. Email **doplexlabs@gmail.com** with the subject "Rotty Lite security", what you found, and how to reproduce it. We'll reply within 3 working days and keep you posted until it's fixed.

Things we especially want to hear about:

- A web page that can read the API key or settings, or make the extension send requests.
- Post text or model output that ends up as HTML or script on the page.
- Anything sent to a host other than the provider the user picked.

## Supported versions

Only the latest release gets fixes.
