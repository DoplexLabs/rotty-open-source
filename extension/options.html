Rotty Lite

The open-source version of Rotty, by Doplex Labs
Runs on your computer, free, and nothing leaves it. Install Ollama, then run:
ollama pull llama3.2 and start it with OLLAMA_ORIGINS=chrome-extension://* ollama serve
Stored only in this browser and sent only to this provider.
